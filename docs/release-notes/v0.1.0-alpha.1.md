First public build of Veneer, a free, open-source finishing stage for the mix bus. **Pre-alpha:** expect rough
edges, and the sound has been measured but not tuned by ear.

Controls: Input trim, Amount (0 to 200%), Weight / Body / Air per band, Push into a true-peak limiter, Output trim,
and meters for input level, gain reduction, loudness and true peak.

## Downloads

| File | Contents |
|---|---|
| `Veneer-v0.1.0-alpha.1-macOS.zip` | VST3, Audio Unit and Standalone, universal (Apple silicon and Intel), macOS 11 or later |
| `Veneer-v0.1.0-alpha.1-Windows.zip` | VST3 and Standalone, 64-bit |
| `Veneer-v0.1.0-alpha.1-Linux.tar.gz` | VST3 and Standalone, 64-bit |
| `SHA256SUMS.txt` | Checksums of the three files |

Each archive has an `INSTALL.txt`. The macOS builds are signed ad hoc, not with an Apple Developer ID, and are not
notarised, so macOS blocks them until you clear the download flag (the commands are in `INSTALL.txt`).

## What has been tested

- 110 unit tests pass on macOS, Linux and Windows in CI.
- pluginval at strictness 10 passes on the macOS VST3 and Audio Unit, and `auval` passes on the Audio Unit, in CI.
- REAPER 7.43 on an Apple silicon Mac, VST3: the plug-in loads and reports 158 samples of latency, an offline render
  matches the engine to within 24-bit rounding, bypass is bit-exact, saved state comes back (including from a project
  saved in an earlier session), and the editor opens and closes.

## What has not

- Logic Pro, or any host other than REAPER.
- The Windows and Linux builds in any host. CI builds and unit-tests them, nothing more.
- The Intel half of the macOS build. It is built, never run.
- Realtime playback in a host. The REAPER check was an offline render.
